Everything a personal agent should do

Not a toy. A companion that works while you sleep.

Two ways to talk

Message it on Telegram or open the dashboard. Both hit the same brain, with streamed answers and a stop button.

Persistent memory

Every exchange, fact and preference is stored in Postgres and recalled at the start of new sessions. It knows you.

Watch that only pings on change

Pages, mailboxes, GitHub repos, servers, stocks. It alerts when something actually changes — never on a loop.

Scheduled jobs

A morning brief, a market close, a weekly report. Recurring prompts with retries and a full report in the dashboard.

Push you can act on

Tap a notification and Mav opens a chat that explains the alert — context, why it matters, what to watch next.

Your agents, your rules

Edit the agent instructions and your MCP servers right in the dashboard. Create new agents. Restart the engine in one click.

An orchestrator built in

A default agent that analyses a request, convenes the right specialists, has them challenge each other, then synthesises.

Private by design

Self-hosted. Your data stays on your machine. No account, no cloud, no telemetry — just your model.

Running in three steps

From a fresh machine to a working companion in minutes.

  1. 1

    Install

    One command. A wizard asks a few things once, then installs Postgres, certificates, services and a mav command.

    curl -fsSL …/get.sh | sudo bash
  2. 2

    Plug your model

    Pick Ollama (local), Claude, OpenAI or any OpenAI-compatible endpoint. Your key, your endpoint, your model.

    provider: ollama · model: llama3.1
  3. 3

    Talk, and let it work

    Message it on Telegram or open the dashboard. Set a watch, add a job, and it starts coming to you.

    mav update · mav status · mav logs

Simple, self-contained architecture

An opencode engine does the thinking. A Telegram bridge and a web dashboard sit on top. Postgres holds the memory. All yours.

  • Three systemd services, nothing more
  • Postgres in Docker, schema applied automatically
  • TLS + Web Push set up for you
  • Idempotent installer and painless updates
